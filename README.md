📝 Simple Python Task CLI — Phase 1
Welcome to the Task CLI Application! This is a lightweight, efficient, and user-friendly command-line tool built with Python to help you manage your daily chores with ease.

🚀 Features
✨ Add Tasks: Quickly add new items to your list.

📋 View Tasks: Display all your pending and completed tasks in a clean list.

✅ Complete Tasks: Mark tasks as done using their unique ID.

🗑️ Delete Tasks: Remove unwanted tasks from your list instantly.

🎨 Custom UI: Clean menu interface with intuitive navigation.

🛠️ Tech Stack
Language: Python 3

Logic: Object-Oriented Programming (Classes & Methods)

Storage: In-memory (Fast and temporary for Phase 1)

💻 How to Run
Follow these steps to get the app running on your machine:

Navigate to the project folder:

cd /mnt/d/hackathon-2-todo/phase-1

Launch the Application:

python3 todo.py
